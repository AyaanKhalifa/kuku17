# 🍁 Happy Birthday Maitri! 🎂🍂

A personalized, interactive birthday celebration website created with love by **Ayaan** for **Maitri** (October 17th).

✨ **Live Preview**: Built with Vite + React + Vanilla CSS

---

## 🌟 Highlights & Features

- 🍁 **Real Autumn Vibes**: Falling autumn maple leaves with gentle swaying animations.
- 🖼️ **Glowing Photo Showcase**: Elegant circular frame with a glowing pulse ring.
- ⌨️ **Dynamic Typewriter Greeting**: Animates Maitri's name with a live cursor.
- 🐾 **Cute Animated GIF Buddies**: Floating party companions flanking the photo and guiding visitors.
- ⏳ **Live Birthday Countdown**: Automatically calculates days until October 17th.
- 🌷 **Blooming Mountain Tulip Strip**: Colorful blooming flowers bobbing softly.
- 🎁 **Surprise Pop-up Modal**:
  - Interactive **Blowable Birthday Candles** 🕯️ (click each candle to blow it out!)
  - Cute celebration GIF squad (Birthday Cat, Mewmew, Dancing Cat)
  - Emotional, personal birthday note from Ayaan to Maitri
  - Full-screen multi-color confetti cannon 🎊
- 🖱️ **Click-Anywhere Particle Burst**: Tap anywhere on screen to burst autumn leaves and hearts.

---

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **Canvas-Confetti**
- **Vanilla CSS (Custom Design System & Keyframe Animations)**

---

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/AyaanKhalifa/kuku17.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
